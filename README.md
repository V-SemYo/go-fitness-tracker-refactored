# go-fitness-tracker-refactored 🏃

Рефакторинг учебного модуля фитнес-трекера с применением принципов ООП и улучшенной архитектуры.

---

## Описание / Description

**RU**: Этот проект — результат рефакторинга учебного фитнес-трекера из курса Яндекс.Практикума. Код был переработан с использованием объектно-ориентированного подхода для улучшения читаемости, тестируемости и масштабируемости.

**EN**: This project is a refactored version of a fitness tracker module from Yandex.Practicum course. The code was redesigned using OOP principles to improve readability, testability, and scalability.

---

## Цель рефакторинга / Refactoring Goals

- ✅ Переход от процедурного стиля к ООП (структуры с методами)
- ✅ Улучшение модульности и разделения ответственности
- ✅ Повышение покрытия кода тестами
- ✅ Упрощение добавления новых типов тренировок

---

## Тестирование / Testing

Проект содержит юнит-тесты (файлы `*_test.go`), которые проверяют корректность реализации. Тесты автоматически запускаются на GitHub при каждом push.

**Запуск тестов локально**:

```bash
go mod tidy
go test -v ./...
Важно: изменять содержимое тестов запрещено — они являются частью задания.
